Q1 OSI Reference Model
radar2022-23 Q3a (10m) · 2024-25 Q1e · 2021-22 Q6b · near-guaranteed
7-layer ISO framework (1984) — conceptual, not a protocol
Each layer is independent; uses below, serves above
Layers (1→7): Physical · Data Link · Network · Transport · Session · Presentation · Application
Data units: bit → frame → packet → segment → data
Encapsulation top-down at sender, decapsulation bottom-up at receiver
Data Link adds both header and trailer (for error check)
mnemonicAll People Seem To Need Data Processing (L7 → L1)

Q3 Network Topologies

Unit II · Data Link Layer & Medium Access Control
5 topics
Q1 Cyclic Redundancy Check (CRC) ★ all 4 PYQs
radar2021-22 Q4b · 2022-23 Q4a · 2023-24 Q5b · 2024-25 Q2a · the single most repeated numerical
Polynomial division over modulo-2 (XOR) arithmetic
Sender: append r zeros, divide by generator, remainder = CRC
Codeword = data + CRC, exactly divisible by generator
Receiver: divide received word by gen; remainder 0 = OK, else error
Detects: all single-bit; all bursts of length ≤ r; most longer bursts
Used in Ethernet, Wi-Fi, HDLC, IPv4 header (header-only)
worked: D=110101, G=x³+x+1 (=1011)Augmented = 110101000 · divide by 1011 → remainder 111
Codeword = 110101111 · Receiver ÷ 1011 → remainder 000 ✓
Q2 CSMA/CD vs CSMA/CA
radar2022-23 Q2b (10m) · 2021-22 Q5b
CSMA core: sense the channel before transmitting
Persistence modes: 1-persistent · non-persistent · p-persistent
CSMA/CD (wired, 802.3): detect collision while sending → abort + jam + binary exponential back-off
CD needs frame time ≥ 2·Tp ⇒ min frame size in Ethernet
CSMA/CA (wireless, 802.11): cannot detect collisions while TX (hidden terminal)
CA tools: IFS + random back-off + RTS / CTS + explicit ACK
Q3 Sliding-Window Protocols (S&W · GBN · SR)
radar2021-22 Q2c/2d/3a/3b · 2022-23 Q2d · 2023-24 Q2b
Stop-and-Wait: send 1 frame, wait ACK; 1-bit seq#
Go-Back-N: sender window = 2ᵐ−1, receiver window = 1, cumulative ACK
GBN on loss → retransmit lost frame + everything after
Selective Repeat: sender & receiver windows = 2ᵐ⁻¹, individual ACK
SR retransmits only the lost frame; receiver buffers out-of-order
Comparison ↑ efficiency: S&W < GBN < SR
Stop & Wait efficiencyη = 1 / (1 + 2a) where a = Tp / Tt
Large a (long link or high BW) ⇒ poor utilisation
Q4 Error Detection & Hamming Code
radar2022-23 Q1g (Hamming) · 2022-23 Q4b · 2023-24 Q2b
Detection: Parity · 2-D Parity · Checksum · CRC
Correction (FEC): Hamming code — detects + locates + fixes single-bit error
Parity bits at positions 2⁰, 2¹, 2², …
Constraint: 2ʳ ≥ m + r + 1 (m=data bits, r=parity bits)
Cᵢ checks every position whose binary has bit-i set
Error position = (Cᵣ … C₂ C₁) read as binary
worked: received 1110101 (2022-23 Q1g)C1=0 ✓ · C2=1 ✗ · C4=0 ✓ → C4 C2 C1 = 010₂ = position 2
Flip bit 2 → corrected codeword 1010101
Q5 Random Access — ALOHA & CSMA
radar2023-24 Q4b (10m) · 2024-25 Q3a (slotted ALOHA numerical)

Q1 Distance-Vector Routing & Count-to-Infinity
radar2021-22 Q4a · 2022-23 Q1j · 2024-25 Q4a + Q4b · dominant routing question
Based on Bellman-Ford equation; decentralised, dynamic
Each router keeps a distance vector; periodically shares with neighbours
Update rule: D(x,y) = min over z [ c(x,z) + D(z,y) ]
Good news fast, bad news slow → count-to-infinity
Mitigations: define infinity (RIP=16) · split horizon · poison reverse · hold-down timers
RIP is the classic DVR protocol
worked: router C (2024-25 Q4b)Via B (+6): (11,6,14,18,12,8) · Via D (+3): (19,15,9,3,12,13) · Via E (+5): (12,11,8,14,5,9)
C's table: A=11/B · B=6/B · C=0 · D=3/D · E=5/E · F=8/B

Q3 IPv4 vs IPv6
radar2022-23 Q5a · 2023-24 Q2c · 2024-25 Q5a
IPv4: 32-bit, dotted decimal, ~4.3B addresses, exhausted
IPv6: 128-bit, hex colon, practically unlimited
IPv4 header: variable 20–60 B, has checksum, 12 fields
IPv6 header: fixed 40 B, no checksum, 8 fields
IPv6 drops broadcast (uses multicast + anycast)
Extension headers chain via "Next Header" — routers process only what they need
IPv6 features: IPSec built-in · SLAAC auto-config · Flow Label for QoS
IPv6 fragmentation only by sender, not routers
Q4 Congestion Control — Leaky vs Token Bucket
radar2022-23 Q2c · 2023-24 Q1f · 2024-25 Q1f + Q2c · rising frequency
Congestion = router queues overflow → drops → retransmits → collapse
Open-loop: prevent in advance (policy) · Closed-loop: react via feedback
Leaky bucket: output at constant rate, smooths bursts, excess discarded
Token bucket: tokens added at rate, allows burst up to bucket size
Token bucket gives idle credit; leaky bucket does not
Token-bucket regulator never drops packets itself
Q5 ARP · RARP · DHCP · ICMP
radar2021-22 Q2e (ICMP) · 2022-23 Q1f · 2024-25 Q5b
ARP: IP → MAC; broadcast request, unicast reply, ARP cache
RARP: MAC → IP; obsolete, superseded by BOOTP / DHCP
DHCP: dynamic IP + mask + gateway + DNS via lease
DHCP four-step DORA: Discover · Offer · Request · Ack
ICMP: error reporting (no error correction); also query messages
ICMP messages: dest unreachable · time exceeded · source quench · redirect · echo

Q2 TCP Segment Header
radar2023-24 Q2d (10m) · 2024-25 Q6b
Src + Dst Port (16 b each) · Seq # (32 b) · Ack # (32 b)
HLEN (4 b) · Reserved (6 b) · Flags (6 b)
Flags: URG · ACK · PSH · RST · SYN · FIN
Window size (16 b) — basis of flow control
Checksum (16 b) over header + data + pseudo-header
Urgent Pointer (16 b) + Options (variable, e.g. MSS, window scaling)

Q3 Connection Management · 3-Way Handshake
radar2023-24 Q6a (10m) · 2024-25 Q6b
Establishment (3-way): SYN → SYN+ACK → ACK
Client: seq=x · Server: seq=y, ack=x+1 · Client: ack=y+1
Three (not two) so both confirm each other's seq #
Prevents old duplicate connection from being established
Termination (4-way): FIN → ACK → FIN → ACK
Half-close: one side sends FIN, still receives data
After last ACK, brief TIME-WAIT state before full close
Q4 TCP Congestion Control
radarcore syllabus · pairs naturally with flow control & QoS
Two windows: receiver-advertised + cwnd (congestion window)
Sender uses min(rwnd, cwnd)
Slow Start: cwnd starts at 1 MSS, doubles each RTT until ssthresh
Congestion Avoidance: cwnd += 1 MSS per RTT (linear)
Timeout: ssthresh = cwnd/2, cwnd = 1, restart Slow Start
3 dup-ACKs: Fast Retransmit + Fast Recovery (cwnd = ssthresh)
AIMD — Additive Increase, Multiplicative Decrease — the heart of TCP's stability

Q2 Cryptography & RSA
radar2022-23 Q2e · 2023-24 Q7b · 2024-25 Q2d · in 3 of 4 papers
Goals: confidentiality · integrity · authentication · non-repudiation
Symmetric: one shared key (DES, AES); fast, key-distribution hard
Asymmetric: public + private key pair (RSA); solves key distribution
RSA steps: pick p, q primes → n=pq, φ=(p−1)(q−1)
Choose e with gcd(e, φ)=1 · find d with e·d ≡ 1 (mod φ)
Encrypt: C = Mᵉ mod n · Decrypt: M = Cᵈ mod n
worked: p=3, q=11n=33 · φ=20 · e=7 · d=3 (because 7·3 = 21 ≡ 1 mod 20)
M=6 → C = 6⁷ mod 33 = 30 → M = 30³ mod 33 = 6 ✓
